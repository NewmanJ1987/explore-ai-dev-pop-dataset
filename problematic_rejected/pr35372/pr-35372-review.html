Critical wiring bug detected. CAMUNDA_OPTIMIZE_DATABASE in ConfigurationServiceConstants equals the string "CAMUNDA_OPTIMIZE_DATABASE" — not "camunda.database.type". The System.setProperty() call in Main.java therefore sets the wrong key and never activates the @ConditionalOnProperty on OptimizeDatabaseConfiguration. Integration tests inadvertently mask this by setting "camunda.database.type" directly, bypassing overrideOptimizeDatabaseType() entirely.
